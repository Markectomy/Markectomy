## About Me

I work on Paper plugins and Fabric mods, from small quality-of-life tools to larger gameplay systems that connect with each other. I like making things that fit Minecraft and make building, organising, and playing easier.

- **Gameplay:** custom creatures, combat, progression, and mechanics that interact with the world.
- **Creative tools:** blueprints, building workflows, and interfaces that are useful when you're actually playing.
- **Beyond code:** resource packs, custom entity assets, map design, worldbuilding, and redstone.
- **My approach:** build it, test it in-game, and refine the details while keeping the code manageable as the project grows.

<h3 align="center">Axiom Blueprint Items</h3>

<p align="center">
  <strong>Your saved blueprints, right in your inventory.</strong><br />
  An unofficial Fabric addon that turns saved Axiom blueprints into reusable creative inventory items.
</p>

- **Find your builds** by name or tags, with support for nested library folders.
- **Preview them before placing** with rotating 3D previews, plus lightweight and static options.
- **Place them** using Axiom's familiar controls, with repeated copies and undo support.

## How I Build

I want custom features to feel like they belong in vanilla Minecraft. Consistent pixel scale, blocky models, and familiar interfaces matter to me, even when the systems behind them are completely custom. That goes for creatures, dialogue screens, and new mechanics too. They should fit the game's existing style.

For the code, I care about clear responsibilities, reusable systems, and predictable behaviour. I test things through actual gameplay and work on the controls, visuals, and performance together. I also like mechanics that happen in the world itself, like physical crafting interactions, and tools that fit how you already build and play.
